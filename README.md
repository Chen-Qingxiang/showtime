# Showtime Timeline

一个面向**历史 / 文学 / 地质 / 宇宙演化**等跨尺度研究场景的可视化时间轴工具。  
你可以把不同来源的 CSV 作为不同图层叠加，对同一问题进行“宏观到微观”的联动观察。

---

## 核心能力

- **多图层时间轴**：每个 CSV 自动成为一个 layer，可拖拽调整顺序、右键删除。  
- **多尺度缩放**：支持从近现代历史到地质史、宇宙史的连续缩放。  
- **双数据入口**：既可一次上传多个本地 CSV，也可直接加载仓库内置示例。
- **灵活时间解析**：支持年份、日期、BCE/CE、区间、单点时间，兼容多种分隔符。
- **ZIP 批量导入**：可把一组 CSV 打包上传，按文件名排序后批量成为图层。
- **背景层库**：内置通用历史、思想、宗教、科技、经济、文学艺术和地质生命背景层，可按当前数据推荐加载。
- **可读性优化**：大数字年份会自动以 `万 / 亿` 显示，减少长数字阅读负担。  
- **哈雷纪年**：可开关的第二标尺，以真实的哈雷彗星回归提供约一代人生的尺度，保留公元主轴；支持回归说明、连续 H 坐标及人物生卒年查询接口。

## 快速开始

1. 打开页面后，可先点击 **加载左侧文本** 体验默认数据。  
2. 通过顶部 **内置示例** 选择器，可一键加载不同学科的数据层。  
3. 通过顶部 **背景库** 选择器，可叠加通用参照层；也可以点击 **加载推荐背景**，让工具按当前主题和时间范围自动选几层。
4. 也可上传本地 CSV（两列：`time,title`），支持一次多选；还可以上传 ZIP，ZIP 内前 100 个 CSV 会按文件名排序后作为独立图层导入。

## 哈雷纪年 / Halley Scale

第二标尺**默认开启**，可在 **显示 → 哈雷纪年** 关闭，手动开关会被记住。每次回归的淡竖线贯穿所有图层，回归标签可以悬浮或点击查看；手机可轻触查看。“哈雷纪年资料”提供全部回归、原表日期、数据来源和定位按钮。

“显示 → 人物与哈雷”可选苏轼示例、已导入的时间区间，或输入姓名和生卒年份/日期，查看H跨度、期间回归与年龄。桌面点击区间也可打开面板。年月精度保留边界不确定性；输入不修改CSV。

“显示 → 哈雷观测史料”收录中国、巴比伦和欧洲的9条精选记录。可按回归查看来源，并加载为按文明分组的普通图层；同一记录不会重复加入。观测日、可能日期窗口和图像关联年份与近日点分开，图层仍可隐藏、重排、改色或删除。

- `H0 = 公元前240年`；`H17 = 1066`；`H28 = 1910`；`H29 = 1986`；`H30 = 2061`。
- 每一段按相邻的实际/计算近日点插值，不使用固定75年步长。中等缩放出现半 H 或四分之一 H 刻度；精细缩放仍以公元日期读数为主。
- 当前日期表覆盖 **H−16（前1404年）至 H30（2061年）**。超出日期表返回 `null`，不虚构更早或更晚的回归。
- 区分历史观测、轨道反算、存疑认定和未来预测。前613年的《春秋》记录不作为确认观测，锚点保持在反算的前616年。
- 古代原表采用儒略历，已统一到主轴使用的公历坐标；资料中同时保留原历法。年份精度的人物年龄是估算，不表示本人曾亲眼观测。
- CSV 内容与图层数据不会随界面语言变化；原有裸负数时间值保持原样。明确表示BCE建议写 `240BC` / `240BCE` / `公元前240`，它们的内部值为 `-239`。主轴显示不再把内部值0写成公元0年。

完整来源、47次回归列表和接口说明见 [docs/halley-scale.md](docs/halley-scale.md)。本地运行 `npm test` 测试转换与绘图边界；通过 HTTP 服务打开 [tests/browser.html](tests/browser.html)，可以运行桌面/手机尺寸的真实浏览器回归检查。

## CSV 格式说明

Showtime 的 CSV 只需要两列：第一列是时间，第二列是标题。

```csv
time,title
1949-10-01,中华人民共和国成立
1969-07-20 20:17:40,阿波罗11号登月
1914-07-28~1918-11-11,第一次世界大战
```

实际导入时，表头可以保留，也可以省略。以 `#` 开头的行会被忽略，适合写注释。

### 列定义

| 列 | 必填 | 说明 |
| --- | --- | --- |
| `time` | 是 | 年份、日期、单点时间或时间区间 |
| `title` | 是 | 事件标题，会显示在时间轴上 |

图层名不写在 CSV 里：上传文件时使用文件名作为图层名；一次多选时每个 CSV 会单独成为图层；从左侧文本框加载时使用 `文本` 图层；背景库会使用 `背景：xxx` 图层名。

### `time` 的写法

| 写法 | 示例 | 说明 |
| --- | --- | --- |
| 公元年份 | `1949` | 单点年份 |
| BCE 年号 | `221BC`、`221BCE`、`公元前221` | 按无公元 0 年处理，`221BC` 等价于内部值 `-220` |
| 内部负数年份 | `-221` | 原样采用天文年坐标，对应222 BCE；保留已有裸负数CSV的时间位置 |
| 公元年月 | `1949-10` | 精确到月，目前只支持公元年份 |
| 公元日期 | `1949-10-01` | 日期格式为 `YYYY-MM-DD`，目前日期只支持公元年份 |
| 日内时间 | `1969-07-20 20:17`、`1969-07-20 20:17:40` | 支持小时、分钟、秒；也可用 `T` 分隔日期和时间 |
| 年份区间 | `1368~1644` | 从开始年份到结束年份 |
| 日期区间 | `1914-07-28~1918-11-11` | 精确到日的区间 |
| 开区间 | `1949~`、`1949-10-01~`、`1969-07-20 20:17~` | 自动补到当前年份、日期或对应日内精度 |

推荐用 `~` 分隔区间。工具也兼容 `-`、`—`、`–`、`－`、`〜`、`～`、`至`、`到`，但在生成 CSV 时统一用 `~` 最不容易出错。

### 标题与逗号

CSV 用逗号分列。如果标题里有逗号，请用英文双引号包起来：

```csv
1942,"《春望》, 杜甫相关研究节点"
```

如果标题里有双引号，用两个双引号转义：

```csv
1967,"论文 ""The Medium is the Message"" 出版"
```

### 可复制模板

年份版：

```csv
# time,title
-221~-207,秦
1368~1644,明
1949~,中华人民共和国
```

日期版：

```csv
# time,title
1949-10-01,中华人民共和国成立
1969-07-20 20:17:40,阿波罗11号登月
1914-07-28~1918-11-11,第一次世界大战
```

跨尺度背景版：

```csv
# time,title
-13800000000~-13700000000,宇宙大爆炸与暴涨阶段
-541000000~-485000000,寒武纪
-300000~-200000,早期智人出现
-221~-207,秦帝国
1969-07-20,阿波罗11号登月
```

常见问题：

- 不要用中文逗号 `，` 分隔列；列分隔符必须是英文逗号 `,`。
- BCE 日期暂不支持 `-221-01-01` 这类写法；BCE 请用年份。
- Excel 可能会自动改日期格式，建议导出后用文本编辑器检查是否仍是 `YYYY-MM-DD`。
- 顶部“点事件显示”可以控制单点事件是否显示成区间条；默认会把单年点显示为全年条，例如 `1647~1647` 显示为 1647 年全年，以减少圆点后长标题重叠。
- 如果某行没有显示，通常是 `time` 无法解析；先用上面的模板试一行最小样例。

## ZIP 批量导入

上传 `.zip` 文件时，Showtime 会在浏览器本地读取其中的 CSV 文件，不会上传到服务器。

- 只导入 ZIP 内的 `.csv` 文件，其它文件会被忽略。
- CSV 会按 ZIP 内文件名排序后依次导入，图层名取自 CSV 文件名。
- 一个 ZIP 最多导入前 100 个 CSV；超过上限的 CSV 会被忽略。
- ZIP 内每个 CSV 仍需符合两列 `time,title` 的时间轴格式。
- 暂不支持嵌套 ZIP，也不会自动调用内置背景库。

## 交互操作

- 拖拽时间轴主体区：默认左右平移；上下意图明显时浏览更多图层。
- 滚轮（时间轴主体区）：围绕鼠标位置缩放。
- 滚轮（左侧图层名区域）：页面上下滚动。
- 左侧图层名区域拖动：调整图层顺序。
- 左侧图层名区域右键：重命名、隐藏、改颜色、删除图层。
- 双击画布 / 点击“重置视图”：快速回到合适视角。

## 项目定位

Showtime Timeline 并非只服务某一条历史线，而是为了支持“**不同时间颗粒度 + 不同学科图层**”的并行观察：  
你可以在同一画面中同时查看宇宙史、地质史、生物演化与人类文明事件，快速建立跨尺度关联。
