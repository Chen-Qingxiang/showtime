# ShowTime

轻量的多图层时间轴，用来把一个人物、事件或研究主题放回更大的历史背景。支持历史、文学、地质与宇宙演化等不同时间尺度。

[在线使用](https://chen-qingxiang.github.io/showtime/)

## 使用

打开后可直接查看默认朝代表，上传 CSV / ZIP、选择内置示例，或从背景库叠加参照图层。拖拽平移，滚轮或顶部滑块缩放；图层名称处可重排，右键可隐藏、改色、重命名或删除。

界面默认**中文、夜间模式**。顶部按钮切换日间 / 夜间，语言和手动选择会被记住；切换不会改写用户 CSV。

CSV 只需要两列 `time,title`，表头可选，`#` 开头为注释。一个文件对应一个图层；ZIP 在浏览器本地读取，最多导入前100个CSV。

```csv
time,title
240BC,公元前240年
1037~1101,苏轼
1949-10-01,中华人民共和国成立
1914-07-28~1918-11-11,第一次世界大战
1949~,中华人民共和国
```

年份、年月、公元日期和日内时间均可用；区间推荐以 `~` 分隔。标题含英文逗号时用双引号包裹，双引号写成 `""`。BCE 请用 `240BC`、`240BCE` 或 `公元前240`；没有公元0年。旧CSV的裸负数仍按原内部坐标解释：`-240` 与 `240BC` 不相同。BCE 暂只支持年份。

## 哈雷纪年

**默认关闭**，在“显示 → 哈雷纪年”勾选开启。公元主轴负责定位，同一颗彗星的回归提供约一代人生的尺度；哈雷标尺跟随缩放和平移。

`H0 = 前240年`，`H17 = 1066年`，`H29 = 1986年`，`H30 = 2061年`。以相邻近日点插值，周期逐次变化，使用固定75年会丢失这些变化。坐标与跨度显示一位小数；事件气泡的哈雷部分只有这两行。

目前覆盖 **H−53（约前4085年）至 H30（2061年），共84次回归**。“哈雷纪年资料”可查看来源和定位；“人物与哈雷”支持生卒年查询；“哈雷观测史料”提供9条精选记录并可加载为图层。

## 数据来源与精度

| 范围 | 日期来源 |
| --- | --- |
| 前240年以来的历史回归 | 历史观测约束轨道；前1404年—1910年的近日点采用 [Yeomans & Kiang（1981），Table 4][yk]；史料补充见 [Stephenson 等（1985）][babylon] |
| 前1404年至前315年 | 同一论文的轨道反算；候选史料的认定与计算日期分开 |
| 约前4085年至前1475年 | 本项目数值扩展：YK81轨道初值、[JPL DE441][de441] 行星初始状态、[REBOUND / IAS15][ias15] 积分；新增37次，标为“模型推算” |
| 1986年与2061年 | [NASA][nasa] 公布到日的日期；2061年为预测 |

越早的轨道约束越弱，**前1404年以前不是已确认的历史日历**，新增日期也不是NASA发布的哈雷星历；产品仅显示模型约年。计算收敛不等于天体真实轨道的准确度，长期局限参见 [Egal 等（2020），§2.4][egal]。前613年《春秋》记录不列为确认观测，反算锚点仍是前616年。

[完整84次列表、模型假设、可复现输入与接口](docs/halley-scale.md)。公元 / BCE 转换保持无历史0年，古代原历法与近日点时标保留在资料中。

## 开发

纯 HTML / CSS / JavaScript 与 Canvas，静态 GitHub Pages；没有框架或新增浏览器运行依赖。

`npm install` 后执行 `npm run dev`。`npm test` 检查坐标、日期与渲染边界；通过 HTTP 打开 [tests/browser.html](tests/browser.html) 检查桌面 / 手机尺寸的真实页面。早期轨道生成只用于离线维护，命令和依赖见上面的模型文档。
