# 哈雷纪年 / Halley Scale

## 目的与接入方式

以同一真实天体的回归串起不同文明与一代代人生。公元轴继续负责精确位置，哈雷轴负责尺度感。现有 vanilla HTML/CSS/JS、Canvas、CSV/ZIP、图层和 GitHub Pages 架构均保留，没有增加运行依赖。

主轴坐标是线性的天文年加公历年内比例：`x = leftPad + (time - viewStart) * pxPerYear`。新数据先用儒略日数转换到同一坐标，再调用现有映射。只增加44px标尺高度，不改变缩放或平移的坐标。

标尺默认关闭；手动开关会被记住。首次打开默认中文、夜间主题；顶部按钮切换日间与夜间。主题同时作用于DOM控件、Canvas和哈雷标尺，切换保留时间位置与CSV。事件气泡的哈雷区只有坐标和跨度，显示一位小数，点事件跨度为0.0 H。模型内部仍保留完整计算精度。

`H(t) = n + (t - P_n) / (P_(n+1) - P_n)`；按各次实际/计算近日点插值。整数回归线始终来自日期表。半 H / 四分之一 H 是时间上的等分，不表示轨道位置或半周运行位置。最远缩放合并密集的绘图标记，最细缩放隐藏弱分刻度；不会外推日期表。

## 来源与日期约定

1. [Yeomans & Kiang (1981)](https://articles.adsabs.harvard.edu/pdf/1981MNRAS.197..633Y)，MNRAS 197, 633–646，DOI 10.1093/mnras/197.3.633。采用第643页 Table 4 的 **T 儒略日数**，覆盖前1404年至1910，共45个轨道锚点。不要用旁边的 osculating period 来生成等间隔回归。原表早于1582年为儒略历，之后为公历，时标为 ET（历书时）。
2. [NASA Science: 1P/Halley](https://science.nasa.gov/solar-system/comets/1p-halley/)：1986年2月9日。
3. [NASA: Halley’s Comet and the Battle of Hastings](https://www.nasa.gov/history/955-years-ago-halleys-comet-and-the-battle-of-hastings/)：最早可靠记录、1066年与贝叶挂毯、多国航天探测及2061年7月28日预测。
4. [Stephenson, Yau & Hunger (1985)](https://www.nature.com/articles/314587a0)，Nature 314, 587–592，DOI 10.1038/314587a0：巴比伦泥板中的前164年与前87年候选观测。该文称为 probable；不把认定置信度当作日期精度。

1986及2061的来源仅给日期，内部锚点取该日开始，`precision: day`。这不表示近日点恰好在午夜。2061为预测。古代ET锚点没有伪造UTC转换，UI按日展示；这是一条历史尺度，不是秒级星历。原表小数位是计算表示精度，不是历史观测准确度；YK81表内古代回归可能误差数天，前240年以前论文估计误差可达约一个月；这不适用于下面新增的早期模型。

`status` 描述回归的历史记录类型，而 `dateBasis` 描述日期的计算来源。二者分开：有历史观测的回归，其近日点仍来自轨道解。`disputed` 是附加认定标志，不移动锚点。前616年对应 `H−5`；前613年的记录不产生额外回归。前466年对应 `H−3`，前467年前后候选记录另作存疑说明。

H0是本项目的纪年约定，不是IAU的彗星命名体系。NASA把前240年的《史记》记录视为最早可靠记录，1981年论文措辞为 probable；界面保留这个区别。

## 前1404年以前的模型扩展

新增37个锚点：**H−53（约前4085年）至 H−17（约前1475年）**。它们来自本项目的数值积分，`status: modelled`、`dateBasis: numerical-extension`，界面使用“≈”和“模型推算”，只显示约年。原有H−16至H30的84个锚点未移动。H编号在这一模型分支上连续，不是新的历史观测认定。

**初值与计算方法：**

- 彗星初值取YK81 Table 4前1404年行：历元JD 1208880.5，近日点JD 1208900.18109，q=0.6203761 AU，e=0.9641090，ω=71.94040°，Ω=11.71491°，i=162.49446°，参考面为B1950黄道。
- 行星初始位置与速度取同一历元的[JPL Horizons / DE441](https://ssd.jpl.nasa.gov/horizons/manual.html)，日心、B1950黄道、AU/day、TDB；[原始响应与查询参数](../data/halley-ancient-seed.json)已保存。采用太阳和9个行星系统质心，地月为一个质点；引力参数取[JPL](https://ssd.jpl.nasa.gov/astro_par.html)。DE441在这里提供初始状态，之后的积分由本项目执行。
- REBOUND 5.2.1 / IAS15积分：牛顿多体引力、太阳一阶后牛顿修正；彗星采用[MSY水冰升华律（1973）](https://articles.adsabs.harvard.edu/pdf/1973AJ.....78..211M)，YK81 Table 3 orbit 3的A1=0.2767×10⁻⁸、A2=0.0150×10⁻⁸ AU/day²保持常数，A3=0。每30天检查径向速度变号，再细化真实近日点；每段周期由计算得出。

**限制：**这是单条名义轨道的项目扩展，不是NASA/JPL发布的哈雷古代星历，也没有复现YK81原来的DE97积分。未拟合新的观测、未建立协方差或轨道克隆集合，未模拟喷气参数长期变化、独立月球与小行星摄动。前1404年以前缺少观测约束，不能据计算小数位推断实际日期精度；参见[Egal等（2020），§2.4](https://arxiv.org/html/2008.03589v1#S2.SS4)。更早的单次日期与回归计数依赖模型分支，本版用于提供历史尺度感。

**复现：**Python环境安装`rebound==5.2.1`并提供C编译器，运行`python3 scripts/generate-halley-ancient.py`，从已提交初值离线生成[data/halley-ancient.json](../data/halley-ancient.json)与`halley-ancient-data.js`。`--fetch-seed`仅在需要重新查询JPL初值时使用；`--epsilon`与`--output`支持收敛对照。浏览器只读静态结果，无天文计算依赖。

**计算检查：**IAS15容差1e−11与1e−13得到相同37次回归与年份，近日点最大差0.0005天（约43秒）；从初值向未来独立积分一周期，前1334年的控制点与YK81相差0.1423天（约3.4小时）。[检查摘要](../data/halley-ancient-validation.json)保留参数和结果。这些是数值检查，**不构成远古实际轨道的误差范围**。

补充参考：[Park等（2021），DE440/DE441](https://ssd.jpl.nasa.gov/doc/de440_de441.html)，DOI 10.3847/1538-3881/abd414；[Rein & Spiegel（2015），IAS15](https://doi.org/10.1093/mnras/stu2164)；Marsden、Sekanina与Yeomans（1973），AJ 78, 211–225，DOI 10.1086/111402。

## 数据模型与接口

浏览器全局 `window.ShowtimeHalley`；Node 使用 `require('./halley.js')`。已出版表与元数据在 `halley-data.js`，新增模型数据在 `halley-ancient-data.js`，转换在 `halley.js`，绘图、回归说明与小型资料面板在 `halley-scale.js`。模型、记录和来源元数据只读。

- `returns` / `getReturn(h)`：回归记录，包含 `h`、`historicalYear`、`julianDay`、主轴 `time`、记录类型、存疑标志和来源。
- `toHalley(time)` / `fromHalley(h)`：连续坐标双向转换；不支持的范围和非有限输入返回 `null`。
- `returnsBetween(start, end)`：闭区间内的回归；`span(start, end)`：有符号 H 跨度。
- `lifetimeSummary(birth, death, options)`：人物接口，含回归、当时年龄、约数标志、出生/死亡年份边界不确定性和数据覆盖情况。年精度死亡区间包括死亡年全年；跨度按输入端点计算。
- `historicalToAstronomicalYear` / `astronomicalToHistoricalYear`：严格处理没有历史0年的BCE/CE转换。历史年0无效；内部天文年0表示1 BCE。
- `calendarToJulianDay` / `julianDayToCalendar` / `julianDayToTimeValue` / `timeValueToJulianDay`：公历、儒略历与现有时间值之间的转换。数值年参数使用天文年编号。

`lifetimeSummary(1037, 1101)` 内部返回约0.8216 H，界面显示0.8 H，期间有H17，年份估算29岁。精确生日可传现有日期时间值并指定 `birthPrecision: 'date'`；满岁按公历生日比较，处理闰年差异。没有从“人生与回归重叠”推断本人曾看到彗星。

既有裸负数CSV原样解释为内部坐标，`-240` 与明确的 `240BC` 并不相等。此版本保留输入规则和已有图层位置，修正显示年号时的零年问题。需要准确BCE语义的新CSV请写 `240BC` / `240BCE` / `公元前240`（内部值-239）。

## 人物 / 区间面板

`halley-panels.js`接到既有CSV解析、图层和视图函数。人物面板提供苏轼示例、导入区间选择与手动生卒输入，不写入或改动CSV。区间端点按生卒理解时，距起点的年数可读作年龄；王朝等非人物区间仍可以查询，但不应将结果当作人的年龄。桌面轻点区间打开面板，手机保留原有区间轻触气泡，通过显示菜单选择人物。

年份年龄为约数，日期年龄按公历生日计算；月份年龄仍标记约数。死亡年份覆盖全年，死亡月份仅覆盖该月。落在生卒年/月内的回归保留边界不确定性。覆盖范围不足时明确提示，不据此认定本人曾看到彗星。
