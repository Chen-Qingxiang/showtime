# ShowTime 系统 review · 2026-10-02

这次按“导入研究主题 → 叠加背景 → 定位与比较 → 管理图层”的实际流程检查产品、代码和页面。新建独立图层的功能原本就有；问题是默认追加、选项位置与操作反馈让人很难发现它。

## 总体判断

主时间坐标与 Canvas 图层模型可以继续使用，当前最需要整理的是围绕它的操作流程。CSV、示例和背景都创建图层，应该共用添加入口；定位、隐藏、重排则属于已有图层的管理。公元轴负责位置，哈雷标尺提供尺度，哈雷分析应由用户明确进入。

没有换框架，也没有重写主轴。本次增加小型 CSV 解析模块和图层菜单模块，仍由 `app.js` 持有唯一图层状态。

## 本次修正

| 问题及影响 | 处理 |
| --- | --- |
| “添加图层”与“背景”分开，用户得先理解数据来源分类才能找到动作 | 合并到“添加图层”，分为 CSV / 示例和背景参照；顶部保留添加、图层、显示、范围四组 |
| 默认追加，文本提交按钮远离编辑区；勾选项容易被忽略 | 默认新建；保留明确的同名追加选项。编辑器显示目标层名和预计动作，支持可选层名与 Ctrl/Cmd+Enter |
| 图层管理藏在右键 / 长按中，手机和键盘用户难以发现 | 增加图层列表：定位、显示/隐藏及更多操作；提供按钮重排，保留原拖拽和右键 |
| 背景添加调用全数据贴合，打断已选好的时间范围 | 添加背景保持缩放和平移；来源 ID 保留在事件模型中，改名后仍可去重；加载中阻止重复请求 |
| 推荐规则把已加载背景也当作研究主题 | 推荐只参考可见的研究数据，排除背景和哈雷观测记录，避免背景引导后续推荐 |
| 隐藏宇宙等长跨度层后，贴合仍使用这些层 | 贴合和范围中心采用可见图层；图层菜单可单独定位某一层。贴合两端留出边距 |
| 桌面单击任意区间都会打开人物面板，朝代也被当成人物 | 普通事件点击显示气泡，与触摸行为一致；人物分析仍可从明确的哈雷工具入口进入 |
| 无效结束日期被当作缺省结束日期，错误事件延伸到现在；`0BC` 等被错误接受 | 只有真正留空的结束端才补到现在；拒绝无效日期、明确 BCE 的零年和中文年份尾部垃圾。保留旧 CSV 裸负数 / 零的内部坐标兼容性 |
| CSV 按物理行分割，带换行的引号标题被拆坏；部分坏日期无声丢弃 | 支持跨行标题、转义引号、BOM、CRLF、注释和可选表头；未闭合引号报出起始行，导入结果提示无效时间行数 |
| 视野外点事件被夹到边缘，文字可越过绘图区；不可见细条仍可能被命中 | 绘制和命中使用同一可见边界；事件区域裁剪，保持事件的真实横坐标 |
| 全局 Canvas 翻译可能改变与 UI 文案相似的用户图层名 / 标题 | 数据文本走原始绘字接口；UI 时间单位单独本地化，不改写用户数据 |
| 手机菜单与侧栏层级冲突，弹出菜单用固定尺寸估算位置；折叠侧栏仍可被 Tab 聚焦 | 调整层级，以实际尺寸限制弹出菜单；折叠编辑器设为 inert；隐藏原生语言选择器退出键盘顺序；补齐焦点样式 |
| 自测在每次正常打开时修改并恢复真实状态，技术信息占据产品界面 | 自测改为显式开发模式；恢复状态时同步画布尺寸和图层列表。移除重复样式规则 |
| 大 CSV 的范围计算使用展开参数，事件很多时可能超出调用栈 | 改为逐项计算边界，加入 14 万事件的回归检查 |

## 架构检查

- 时间映射仍是线性的 `viewStart + pxPerYear`，各图层共用公元轴。显式 BCE 采用天文学内部年号，显示时无历史 0 年；日期、时间精度和开区间约定保留。
- 图层顺序、颜色、隐藏集合与事件数据由同一状态维护；新的 DOM 列表只是入口，操作复用已有图层函数，不另建一份数据状态。
- 哈雷数据、坐标、绘制和资料面板已有分离；84 次锚点及其观测 / 反算 / 模型 / 预测说明保留，气泡继续只有一位小数的坐标与跨度两行。早期模型的物理不确定性没有因 UI 修改而消失，仍见 [精度与来源](halley-scale.md)。
- 用户 CSV 仍是两列，新增来源 ID 属于内部元数据。界面语言、主题切换与导入原文分开。

## 接下来最值得做

| 优先级 | 改进 | 原因与建议边界 |
| --- | --- | --- |
| 高 | 保存 / 打开研究项目，并提供撤销 | 现在只保存界面偏好，刷新会丢失图层、顺序和颜色；删除确认不能代替撤销。先做可下载、可检查的项目文件，继续保留两列 CSV 导入 |
| 高 | 多图层浏览时固定共同时间标尺 | 页面滚到很下面时，Canvas 顶部公元轴会离开视野。应复用当前映射固定标尺，保持上下图层可比较，避免每层发展成独立时间坐标 |
| 中 | 明确研究主题与参照层，增强推荐解释 | 当前仍可能同时导入多个主题。之后可让用户指定主要研究层，显示推荐依据；这次只先排除了背景自我影响 |
| 中 | 大数据绘制与标签布局 | 全高 Canvas、逐事件命中和大量重叠标签仍有规模限制。先用真实大 CSV 建基准，再做可视区域绘制 / 命中索引，避免凭猜测重构 |
| 中 | 收敛主脚本与翻译机制 | `app.js` 仍同时承担日期、状态、交互和内置目录；目录还与 manifest / i18n 存在重复。后续按职责小步提取，逐渐替换全局翻译补丁 |
| 低 | 背景资料的出处与精度标注 | 背景库是粗尺度参照，不是完整历史事实库；来源和日期粒度可逐层补充，而非用更多数据掩盖差异 |

- `npm test`：32 项离线检查通过，包含新 CSV 解析与原有哈雷数据 / 坐标 / 渲染测试。
